# team-13-project
## KDT14기 웹 프로젝트 3팀

### 프로젝트 개요
- 프로젝트명 : 청년정책도우미
- 배경 : 수많은 청년 지원 정책이 존재하지만, 복잡한 자격 조건과 어려운 공고문 용어로 인해 자신에게 필요한 혜택을 놓치는 문제가 발생
- 목표 : 텍스트, 이미지, 지도 등 다양한 인터페이스를 통해 청년들이 정책 정보를 쉽게 탐색하고, 자신에게 맞는 혜택을 즉시 파악할 수 있도록 돕는 AI 웹 서비스를 제공
- 목표이용자 : 정책 정보 탐색에 어려움을 겪는 2030 청년층

### 기능
1) 정책 쳇봇
    - 맞춤형 자격 진단: 사용자의 상황을 파악하여 신청 가능 여부 안내
2) 정책 PDF 공고문 요약 및 분석
    - 다중 PDF 분석: 청년정책 공고문 PDF를 업로드시, 핵심 내용 추출
3) 포스터/현수막 이미지 인식
    - 이미지 분석: 길거리 현수막, 학교 게시판 포스터, SNS 카드뉴스 사진을 업로드시, 정책 설명
4) 지도 기반 지역별 정책 탐색
    - 인터랙티브 지도 : 지도의 특정 지역을 선택하면 해당 지자체의 청년정책을 필터링하여 보여줌
